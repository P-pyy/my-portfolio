# Chrestine Hiangan | Portfolio

My portfolio site for sharing the websites and apps I've worked on, the tools I use, and ways to contact me.

## Run locally

```sh
pnpm install
pnpm dev
```

Open `http://localhost:3000` in your browser.

## Built with

Next.js, React, TypeScript, and Tailwind CSS.

## Project files

- `app/` contains the page entry point, shared layout, and global styles.
- `components/` contains the page sections and project views.
- `public/images/` contains project screenshots, profile images, and technology icons.
